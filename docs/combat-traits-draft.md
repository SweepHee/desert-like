# 전투 특성 시스템 초안 v0.1 (미적용 — 검토용)

> 목표: "최종 유닛 원툴"을 죽이고, **상대 조합을 보고 내 조합을 바꾸는 게임**으로.

## 0. 왜 지금 최종 유닛 원툴이 성립하는가 (진단)

1. 밸런스 패치에서 고티어에 스탯 효율 프리미엄을 줬는데, 그걸 **깎아낼 하드 카운터가 없다.**
   현재 태그(경장/중장/거대)는 보너스 폭이 작고 배정도 산발적이라, 550원 최종 유닛을
   "이 유닛으로 치면 싸게 잡는다"는 답이 존재하지 않음.
2. 최종 유닛은 광역+회복+고방어를 한 몸에 갖고 있어 물량으로도, 정예로도 답이 안 나옴.
3. 결론: **모든 유닛에 명시적 약점(장갑 유형)을 박고, 그 약점을 찌르는 무기를
   저렴한 티어에 골고루 배치**해야 한다. 550원 유닛이 200원짜리 카운터 2기에게
   비용 손해를 보게 만들면 원툴은 자동으로 죽는다.

## 1. 시스템 규칙

### 두 개의 특성 축 + 보조 태그

**① 장갑 유형** (모든 유닛이 정확히 1개):
| 유형 | 의미 | 주로 |
|---|---|---|
| **천** | 무장갑·유리몸 | 마법사, 힐러, 유령, 봉제인형 |
| **가죽** | 경장 (가죽·목재·뼈) | 근접 경보병, 기동 유닛, 짐승 |
| **판금** | 중장 (금속·바위·거목) | 탱커, 고급·최종 유닛 |

**② 존재 유형** (모든 유닛이 정확히 1개):
| 유형 | 의미 | 상호작용 |
|---|---|---|
| **생체** | 살아있는 존재 | 저주·독에 취약, 회복 가능 |
| **망자** | 죽은 것 ("죽음"의 정식 명칭 제안: **망자**) | 신성·정화에 취약, 수리 불가 (기존 규칙 유지) |
| **기물** | 인형·기계 등 무생물 | 화염·번개에 취약, "수리"로만 회복 |

**③ 보조 태그**: **거대** (기존 유지 — 대형 유닛 식별, 처형기의 대상)

### 공격 유형 (무기마다 1개 — 보너스를 결정)

| 공격 유형 | 강함 (보너스 대상) | 플레이버 |
|---|---|---|
| **참격** | 천 | 검·도끼·발톱 — 무방비를 벤다 |
| **관통** | 가죽 | 화살·창·총알 — 가죽을 뚫는다 |
| **충격** | 판금 | 망치·강타·낙석 — 갑주를 으깬다 |
| **마법** | 판금 | 갑옷을 무시하고 태운다 |
| **신성** | 망자 | 정화 — 판데모니엄 카운터 |
| **저주** | 생체 | 생명을 좀먹는다 — 실바린 카운터 |
| **화염** | 기물 | 천·나무 인형이 불탄다 — 마리오네타 카운터 |

### 피해 계산 (현 엔진에 그대로 얹힘)

```
피해 = max(1, 기본공격력 + 유형보너스 − 방어력)
유형보너스 = 기본공격력의 약 50% (반올림, 유닛별 미세조정)
```

표기 예: **공격력 10 (천 +5)** → 천 유닛에게 15, 나머지에게 10.
기존 bonus 시스템이 태그 키만 바뀌는 것이라 **구현 비용은 데이터 교체 수준.**

### 표기 원칙 (UI)

- 상점 카드: `가죽 · 생체` 배지 + `공격 10 (천 +5)` 텍스트
- 상성표를 외우게 하지 말 것 — **보너스가 카드에 그대로 적혀 있으면 된다**

## 3. 이 시스템이 최종 유닛 원툴을 죽이는 방식

최종 유닛은 전부 **판금·거대**로 약점이 공표된다. 각 종족이 테크 2~중급 가격대에
그 약점을 찌르는 유닛을 **최소 2개씩** 보유:

| 목표 | 실바린의 답 | 판데모니엄의 답 | 마리오네타의 답 |
|---|---|---|---|
| 판금 (사도·마몬·태엽인형·탱커들) | 버섯 폭탄병(충격), 드루이드(마법) | 망령(마법), 시체 골렘(충격) | 광대 인형(충격), 앤·앨리스(마법) |
| 거대 (최종·최상급 전반) | 갑옷 마멋(+거대) | 타나토스(+거대) | 광대 인형(+거대) |
| 천 (마법사·힐러 라인) | 고우토·덩굴 사냥꾼 | 망자병·목없는 기사 | 저주받은 인형 |
| 가죽 (경보병 물량) | 엘프 궁수·숲올빼미 | 사냥개·해골 투척병 | 태엽 병정 |
| 생체 (실바린 전체) | — (미러) | 시체술사·밴시 | 캐스퍼 |
| 망자 (판데 전체) | 드루이드 「정화의 빛」 | — (미러) | — (약점: 의도적 공백*) |
| 기물 (마리오네타) | 화염 담당 부재* | 화염 담당 부재* | — (미러) |

\* 의도적 공백 = 삼각 상성의 원천. 화염(대기물)은 실바린·판데 중 **한 곳에만** 주면
삼각형이 완성된다. 제안: **가시 마녀의 「검은 가시」 업그레이드를 화염 가시(기물+)로
변경** (실바린→마리오네타 견제 수단) — 대신 마리오네타→실바린 우세는 저주받은 인형·캐스퍼가 유지.

**비용 효율 목표치** (구현 후 duel.ts로 검증할 기준):
- 카운터 유닛은 자신이 카운터하는 대상과 싸울 때 **비용 대비 1.5배 효율**
- 같은 돈이면: 사도 1기(550) < 광대 인형 2기+수리공 1기(530) — "조합이 답"이 성립
- 반대로 카운터가 아닌 상대에겐 평범 이하 → 원툴 조합은 반드시 찔릴 구멍이 생김

## 4. 기존 시스템에서 바뀌는 것 / 유지되는 것

| 항목 | 처리 |
|---|---|
| 경장/중장 태그 | **천/가죽/판금으로 대체** (전면 재배정) |
| undead/construct 태그 | **망자/기물로 이름만 정리**, 규칙 유지 (수리 불가, 정화 보너스) |
| 생체 태그 | **신설** — 저주 계열의 대상 |
| 거대 태그 | 유지 |
| 방어력(flat) | 유지하되 역할 축소: 0~3 정도로 하향 (상성이 주 방어 수단이 되도록) |
| 방어 무시(망령 궁수 계열) | 제거 → 관통 보너스로 통합 (규칙 단순화) |
| 업그레이드 | 유지 — 일부는 보너스 유형을 바꾸는 업그레이드로 진화 (예: 검은 가시→화염) |
| 표기 | 상점 카드에 장갑·존재 배지 + 괄호 보너스 표기 |

## 5. 보조 제안 (특성만으로 부족할 때의 추가 레버)

1. **최종 유닛 동시 보유 제한**: 부대 구성에 최종 티어 최대 2기 (혹은 1기).
2. **최종 유닛 가격 인상** (550→700) — 특성 도입 후에도 원툴이 남으면.
3. 보급(supply) 상한 활성화 — 예약해둔 필드를 켜서 웨이브당 부대 규모 제한.

## 6. 구현 순서 (승인 시)

1. 태그 교체 + 전 유닛 재배정 (data.ts) — 반나절
2. 무기 보너스 재배정 + 방어력 하향
3. UI 배지/보너스 표기
4. duel.ts 로 카운터 효율 1.5배 목표 검증 매트릭스 (약 20개 결투)
5. 풀게임 삼각 상성 재확인
