# Desertlike — 게임 설계 초안 v0.1

데저트스트라이크/다이렉트스트라이크 계열 3v3 웹 전략 게임.
플레이어는 유닛을 **구매만** 하고, 전투는 자동으로 벌어진다.

## 핵심 루프

1. 유닛을 구매하면 **내 부대 구성(composition)에 영구 추가**된다.
2. 내 슬롯의 출정 차례가 오면 **부대 전체가 복제되어 전장에 출격**한다. (DS 방식)
3. 출격한 유닛은 자동으로 적 넥서스를 향해 진군하며 싸운다. 죽으면 끝 (이월 없음 — 다음 내 차례에 부대가 다시 통째로 출격).
4. 자원은 시간당 지급 + 발전소 업그레이드로 증가. "지금 병력 vs 인컴" 트레이드오프.

## 출정 로테이션 (3v3)

- 준비 시간 **90초** 후 첫 출정.
- 이후 **60초 간격**으로 양 팀의 같은 슬롯이 **동시에** 출정한다.
  - t=90s: 양 팀 1번 유저 / t=150s: 2번 유저 / t=210s: 3번 유저 / t=270s: 다시 1번 유저 …
- 전장은 **하나의 공유 필드**. 슬롯별로 상/중/하 밴드에서 스폰되지만 진군하며 자연히 섞인다.

## 맵 구조 (탑뷰, 가로 진행)

```
[0팀 넥서스]--[0팀 중간기지(수호탑)]--- 중앙 전장 ---[1팀 수호탑]--[1팀 넥서스]
```

- **수호탑(중간기지)**: HP 높고 사거리 긴 방어 타워. 초반 유닛보다 확실히 강함. 이걸 부숴야 넥서스에 접근 가능(사거리·위치로 강제).
- **넥서스**: 최심부. HP·방어력 매우 높고 공격력도 강함. 낮은 티어로는 못 뚫음. 파괴 = 승리.
- **수호자 (컴백 메커니즘)**: 수호탑이 부서지면 **부서진 팀의 수비수**로 그 자리에 젠.
  - 0팀(1진영) = **드래곤**, 1팀(2진영) = **슬리피 할로우**(목 없는 기사). 밸런스 동급, 맛만 다름.
  - 진영별 테마(1진영: 용+숲+엘프 / 2진영: 망자+판데모니엄+시간)는 [setting.md](setting.md) 참조.
  - 비행 + 거대 판정. **대공 가능한 원거리 유닛으로만 타격 가능.** → "수호탑 깨기 전에 대공을 준비하라"는 설계 게이트.
  - 수비형: 젠 위치 주변을 지키며(리쉬) 진군하지 않는다.

## 전투 규칙

- 고정 20틱/초, 정수 고정소수점(1타일=1000) — 서버·클라 완전 동일 재현(결정론).
- 피해 = max(1, 공격력 + 태그 보너스 − 방어력). SC2식 "+X vs 태그" 보너스 시스템.
- 태그: 경장(light) / 중장(armored) / 거대(massive) / 구조물(structure) + 비행 여부.
- 무기 대상: 지상 / 공중 / 지상+공중. 지상 전용 무기는 비행 유닛을 못 침.
- 특수 메커니즘: 힐(왕국 사제), 둔화(마도회 서리술사 — 이속·공속 저하), 스플래시(마도회 모래폭풍 술사).

### 1. 하르마탄 왕국 — 중장 균형형 (구버전)
"단단한 정규군." 유닛 수 적고 비싸지만 튼튼함. 중장 위주 → 부족의 대중장 보너스에 물림.

| 유닛 | 티어 | 공격 | 대상 | 태그 | 역할 |
|---|---|---|---|---|---|
| 방패병 | 기본 | 근접 | 지상 | 중장 | 앞라인 탱크 |
| 석궁병 | 기본 | 원거리 | 지+공 | 경장 | +대경장. 물량 카운터 |
| 사막 기병 | 중급 | 근접(고속) | 지상 | 중장 | +대경장. 후방 원거리 사냥 |
| 공성 발리스타 | 고급 | 원거리(장사정) | 지상만 | 중장 | +대구조물/+대중장. 공성 핵심, 대공 불가 약점 |
| 그리핀 기사 | 비행 | 근접(비행) | 지+공 | 중장 | 기동 타격, 대공 겸용 |
| 태양 사제 | 특수 | 힐 | 아군 | 경장 | 지속전 유지력 |

### 2. 모래엄니 부족 — 경장 물량형
"싸고 많고 빠르다." 기본 유닛 3종, 저비용 스웜. 경장 위주 → 왕국의 대경장·마도회 스플래시에 물림. 대신 대중장·대거대 수단 보유.

| 유닛 | 티어 | 공격 | 대상 | 태그 | 역할 |
|---|---|---|---|---|---|
| 도끼 전사 | 기본 | 근접 | 지상 | 경장 | 값싼 몸빵 |
| 투창병 | 기본 | 원거리 | 지+공 | 경장 | +대비행. 값싼 대공 |
| 하이에나 기수 | 기본 | 근접(고속) | 지상 | 경장 | +대경장. 난입 암살 |
| 피의 광전사 | 중급 | 근접(고DPS) | 지상 | 경장 | +대중장. 왕국 카운터 |
| 전투 매머드 | 고급 | 근접 | 지상 | 중장·거대 | +대구조물. 공성 겸 벽 |
| 모래 와이번 | 비행 | 원거리 | 지+공 | 경장 | 기동 화력 |
| 우레 주술사 | 특수 | 원거리(마법) | 지+공 | 경장 | +대거대/+대비행. 수호자·매머드 카운터 |

### 3. 신기루 마도회 — 원거리 유리대포형
"사거리와 마법." 원거리 편중 + 근접 탱커 골렘 하나. 화력 최고, 몸 최약 → 고속 근접(기병·하이에나·검무사)에 물림.

| 유닛 | 티어 | 공격 | 대상 | 태그 | 역할 |
|---|---|---|---|---|---|
| 화염 술사 | 기본 | 원거리 | 지상 | 경장 | +대경장. 스웜 견제 |
| 서리 술사 | 기본 | 원거리 | 지+공 | 경장 | **둔화 부여**. 유틸 코어 |
| 수정 골렘 | 기본 | 근접 | 지상 | 중장 | 유일한 앞라인 |
| 모래칼날 검무사 | 중급 | 근접(고속) | 지상 | 경장 | +대경장. 침투 견제 |
| 대마도사 | 고급 | 원거리(장사정) | 지+공 | 경장 | +대중장. 최장사정 화력 |
| 스핑크스 | 비행 | 원거리 | 지+공 | 중장 | +대비행. 제공권 |
| 모래폭풍 술사 | 특수 | 원거리(**스플래시**) | 지상 | 경장 | 부족 물량 카운터 |

### 종족 상성 삼각 (소프트)

- **왕국 → 부족**: 석궁·기병의 대경장 보너스가 스웜을 갈아버림.
- **부족 → 왕국**: 광전사 대중장 + 물량이 비싼 중장 라인을 압도. 발리스타는 대공 없음 → 와이번에 무력.
- **마도회 → 왕국/구조물**: 사거리·대중장 마법 화력. 그러나…
- **부족/왕국 → 마도회**: 하이에나·기병 등 고속 근접이 유리몸 술사 라인에 난입하면 붕괴.
- 하드 카운터가 아니라 **비용 효율 우위** 수준으로 유지. 조합으로 극복 가능해야 함.

## 경제 (초안 수치)

- 시작 자금 250. 5초마다 +30.
- 발전소 업그레이드: 비용 200 + 75×레벨, 효과 +8/5초. 언제든 구매.
- 초안에는 보급 상한 없음 (유닛 데이터에 supply 필드만 예약).

## 봇 AI (v1.0, 2026-08-16)

**난이도** (연습 게임 시작 화면에서 선택):
- **쉬움** — 순정 AI.
- **중간** — 봇 인컴이 유저보다 12원 더 많음 (인컴업마다 +12씩: 12, 24, 36…).
- **어려움** — 반응형: 적팀 사람의 인컴·테크를 추격 (모자라면 저축까지 하며 따라옴), 사람의 최다 보유 유닛의 카운터(태그 보너스 + 대공 가능) 유닛을 4배 가중으로 생산.

**성격 4유형** — 게임 시작 시 봇마다 시드 기반 무작위 배정 (결정론):
1. `fastTech` 빠른 테크 + 그리디 — 경제·테크 몰빵, 테크 3 후 고티어 위주 (비용² 가중)
2. `rushThenGreedy` 초반 3웨이브 물량 러시 (잔돈 없이 다 씀) → 이후 그리디 전환
3. `balanced` 고른 밸런스 (기존 성향)
4. `finalOnly` 최속 테크 3 → 이후 최상급·최종 유닛만 구매 (비용³ 가중)

**업그레이드·해금**: 성격별 30~40% 확률로 보유 유닛의 업그레이드 구매. 1000원+ 해금 스킬(세이지 마법·인형의 실)은 60% 가중으로 우선하고, 돈이 모자라면 해금비를 저축한다.

검증: `packages/sim/src/cli/bot-check.ts` (8개 assertion).
