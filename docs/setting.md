# Desertlike — 세계관/설정 v0.1

게임의 진영(팀) 컨셉을 명시하는 설정 문서. 밸런스·유닛 수치는 [design.md](design.md) 참조.

## 진영 컨셉 (확정)

맵의 양쪽 진영은 각각 고유한 테마를 가진다. **진영 컨셉은 NPC·환경 요소(넥서스, 수호탑, 수호자, 맵 연출 등)에 적용되는 것**이며, 플레이어가 고르는 종족과는 무관하다.

| | 1진영 (0팀) | 2진영 (1팀) |
|---|---|---|
| 컨셉 키워드 | **용 + 숲 + 엘프** | **망자 + 판데모니엄 + 시간** |
| 수호자 | 드래곤 | 슬리피 할로우 (목 없는 기사) |
| 적용 대상 | 넥서스·수호탑·수호자 등 NPC/환경 | 넥서스·수호탑·수호자 등 NPC/환경 |

- **1진영**: 용, 숲, 엘프 테마. 수호자 "드래곤"이 이 컨셉에 속한다.
- **2진영**: 망자(언데드), 판데모니엄(마경/혼돈), 시간 테마. 수호자는 **슬리피 할로우** — 목 없는 기사 형상의 수문장 몬스터.

### 공략 순서 (v0.4 확정)

**수호탑 → 수호자(중간보스) → 넥서스** 순서로만 뚫을 수 있다. 건너뛰기 불가.

1. **수호탑** (2,900 HP / 방어 3) — 부수면 그 팀 자리에 **수호자**가 젠되고, 부순 팀 전원이 350원을 받는다.
2. **수호자 = 중간보스** — 0.9초 연타 + 반경 1.7타일 광역. 물량 웨이브를 통째로 갈아버린다. **모든 상태이상 면역** (둔화·독·속박·수면·공포·혼란·빙결·한기·약화·도발·끌어당김·지상화 전부).
   - 넥서스는 **수호자가 죽기 전까지 무적**이며 타겟으로도 잡히지 않는다 (진군 목표도 수호탑 자리까지).
   - **힐러는 수호자를 치유할 수 없다** — 힐러가 중간보스에 눌러앉는 문제 차단.
   - 격파 시 부순 팀 전원 350원.
3. **넥서스** (5,000 HP / **방어 28**) — 기본 티어 평타는 최소 피해 1밖에 못 준다. 공성·고급 유닛(페어리·트렌트·데미리치 등)으로만 실질적으로 깎인다.

## 플레이어 종족

종족별 상세 설정은 `races/` 폴더에 문서화한다.

- 🌲 **[실바린 (Sylvarin)](races/sylvarin.md)** — 숲종족. 숲의 동물 + 엘프 + 자연 마법. "귀엽고 평화로운 자연계 생물들이 무기 들고 전쟁하는 종족." (확정)
- ☠️ **[판데모니엄 (Pandemonium)](races/pandemonium.md)** — 죽음 + 시체 + 공포 + 희생 + 부활. "죽음은 끝이 아니다." 전투가 길어질수록 강해지는 종족. (확정)
- 🧸 **[마리오네타 (Marionetta)](races/marionetta.md)** — 인형 + 장난감 + 태엽 + 단추 + 실 + 유령 + 호러. "모든 것은 태엽이 멈추는 순간까지 움직인다." 태엽과 유닛 간 연결(실)을 활용하며, 순간 폭발력이 강하지만 지속전에 약한 종족. (확정)

**삼각 상성** (같은 실력 기준 약 55:45의 유리함, 종족당 카운터 유닛 2~3개):

```
🌲 실바린 → (강함) → ☠️ 판데모니엄 → (강함) → 🧸 마리오네타 → (강함) → 🌲 실바린
```

- 🌲 실바린 = 전장을 숲으로 만든다.
- ☠️ 판데모니엄 = 전장을 시체로 만든다.
- 🧸 마리오네타 = 전장을 인형극 무대로 만든다.

### 유닛/업그레이드 공통 규칙 (전 종족 적용)

- 유닛은 **기본 스펙 + 기본 패시브/액티브**를 가지고 생산된다. 모든 유닛이 패시브+액티브를 다 가지는 건 아니지만 **대부분** 가진다.
- **유닛은 완성형으로 주어지지 않는다** — 일부 능력은 **추가 업그레이드**로 얻는다. 단, 업그레이드가 아예 없는 유닛도 의도적으로 둔다.
- 업그레이드는 단순 수치 증가(+10%)가 아니라 **상대 조합에 대응하는 선택지**이며, 택1 같은 **기회비용**을 넣어 "어떤 업그레이드를 골랐느냐"가 빌드를 결정하게 한다.
- 업그레이드는 **① 유닛 자체 업그레이드 / ② 종족 공통 업그레이드** 두 종류.
- **밸런스 기준: 초반 유닛도 기본 스펙 자체는 상당히 강하게.** 후반 유닛과의 차이는 단순 능력치가 아니라 **역할·특수능력·업그레이드**에서 만든다.
- 재정의 완료: [실바린 v0.2](races/sylvarin.md), [판데모니엄 v0.2](races/pandemonium.md), [마리오네타 v0.2](races/marionetta.md) — 3종족 전부 이 체계로 정리됨.

### 진영과의 관계

- 플레이어 종족 3종은 **진영과 무관하게 어느 팀에서든 자유롭게 선택 가능**하다.
- 즉 진영 컨셉은 "그 땅의 주인(NPC)"에 대한 설정이고, 플레이어 부대는 어느 진영에 배정되든 자기 종족을 그대로 쓴다.
- 참고: [design.md](design.md)의 사막 3종족(하르마탄 왕국/모래엄니 부족/신기루 마도회)은 구버전 잠정 로스터. 새 종족 설정과의 관계(대체/리테마)는 미정.
